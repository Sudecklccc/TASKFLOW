# TASKFLOW

TASKFLOW, görevlerin oluşturulmasını, listelenmesini, güncellenmesini ve silinmesini sağlayan web tabanlı bir görev yönetim uygulamasıdır.

## Kullanılan Teknolojiler

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- Node.js
- Express.js

## Projeyi Çalıştırma

### 1. Projeyi bilgisayara indirin

```bash
git clone https://github.com/Sudecklccc/TASKFLOW.git
cd TASKFLOW
```

### 2. Backend'i başlatın

Ana proje klasöründe:

```bash
npm install
node index.js
```

Backend sunucusu `http://localhost:3000` adresinde çalışır.

### 3. Frontend'i başlatın

Yeni bir terminal açarak:

```bash
cd frontend
npm install
npm run dev
```

Vite tarafından gösterilen yerel adres üzerinden uygulamaya erişebilirsiniz.

## Proje Özellikleri

- Görev ekleme
- Görevleri listeleme
- Görev güncelleme
- Görev silme
